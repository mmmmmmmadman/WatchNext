## Description / 描述

### English

```
WatchNext helps you discover movies and TV shows across multiple streaming platforms in one place.

Stop switching between apps to find what to watch. WatchNext lets you browse content available on Apple TV, Netflix, Prime Video, and Disney+ with powerful filtering options.

FEATURES

- Browse by Platform: See what's available on your favorite streaming services
- Multiple Ratings: View TMDB, IMDb, and Rotten Tomatoes scores side by side
- Smart Filtering: Filter by genre, sort by popularity or rating
- Region Support: Find content available in your country
- Clean Interface: Minimalist design focused on discovery

HOW IT WORKS

1. Select your streaming platform
2. Choose your region
3. Browse movies or TV shows
4. Filter by genre and sort by rating
5. Tap any title for details

WatchNext uses the TMDB API for movie and TV data. Optional OMDb integration adds IMDb and Rotten Tomatoes ratings.

Note: API keys required for full functionality. Free keys available from TMDB and OMDb.
```

### 繁體中文

```
WatchNext 幫助您在一個地方探索多個串流平台上的電影和電視節目。

功能特色

使用方式

注意：需要 API 金鑰才能使用完整功能。可從 TMDB 和 OMDb 免費取得金鑰。

### Notes for Reviewer
```
English:
This app requires API keys to function. To test:
1. Get a free TMDB API key at https://www.themoviedb.org/settings/api
2. Optionally get a free OMDb API key at https://www.omdbapi.com/apikey.aspx
3. Enter the keys in Settings when prompted

The app displays movie/TV information from TMDB and ratings from OMDb. All data is fetched from these third-party APIs.

繁體中文:
此應用程式需要 API 金鑰才能運作。測試方式：
1. 在 https://www.themoviedb.org/settings/api 取得免費 TMDB API 金鑰
2. 可選擇在 https://www.omdbapi.com/apikey.aspx 取得免費 OMDb API 金鑰
3. 在提示時於設定中輸入金鑰

應用程式顯示來自 TMDB 的電影/電視資訊和來自 OMDb 的評分。所有資料均從這些第三方 API 取得。
