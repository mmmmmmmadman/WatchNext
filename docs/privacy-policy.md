## English

### Overview

WatchNext ("the App") is a movie and TV show discovery application that helps users find content across streaming platforms. This privacy policy explains how we handle your information.

### Data Collection

**What We Collect:**
- **API Keys**: If you provide your own TMDB or OMDb API keys, they are stored locally on your device only.
- **User Preferences**: Your selected region, streaming platform, and filter settings are stored locally.
- **Cache Data**: Movie and TV show information is temporarily cached on your device for better performance.

**What We Do NOT Collect:**
- Personal identification information
- Location data
- Usage analytics
- Browsing history beyond the local cache

### Data Storage

All data is stored locally on your device using Apple's SwiftData framework. No data is transmitted to our servers because we do not operate any servers.

### Third-Party Services

The App uses the following third-party APIs:

**TMDB (The Movie Database)**
- Purpose: Movie and TV show information, posters, and streaming availability
- Data shared: API requests with your selected region
- Privacy Policy: [https://www.themoviedb.org/privacy-policy](https://www.themoviedb.org/privacy-policy)

**OMDb API**
- Purpose: IMDb and Rotten Tomatoes ratings
- Data shared: Movie/TV show identifiers for rating lookup
- Privacy Policy: [https://www.omdbapi.com/legal.htm](https://www.omdbapi.com/legal.htm)

### User Control

You have full control over your data:
- **Delete API Keys**: Remove your API keys anytime in Settings
- **Clear Cache**: Delete the app to remove all cached data
- **No Account Required**: The app works without creating any account

### Children's Privacy

The App does not knowingly collect information from children under 13. The app displays movie ratings and content information which may include mature themes.

### Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected in the "Last Updated" date above.

### Contact

For questions about this privacy policy, please open an issue on our GitHub repository:
[https://github.com/mmmmmmmadman/WatchNext](https://github.com/mmmmmmmadman/WatchNext)

## 繁體中文

### 概述

WatchNext（以下簡稱「本應用程式」）是一款電影與電視節目探索應用程式，幫助使用者在各串流平台上尋找內容。本隱私權政策說明我們如何處理您的資訊。

### 資料收集

**我們收集的資料：**
- **API 金鑰**：如果您提供自己的 TMDB 或 OMDb API 金鑰，它們僅儲存在您的裝置本機上。
- **使用者偏好設定**：您選擇的地區、串流平台和篩選設定儲存在本機。
- **快取資料**：電影和電視節目資訊會暫時快取在您的裝置上以提升效能。

**我們不收集的資料：**
- 個人身份識別資訊
- 位置資料
- 使用分析數據
- 本機快取以外的瀏覽記錄

### 資料儲存

所有資料都使用 Apple 的 SwiftData 框架儲存在您的裝置本機上。由於我們不營運任何伺服器，因此沒有資料會傳輸到我們的伺服器。

### 第三方服務

本應用程式使用以下第三方 API：

**TMDB（The Movie Database）**
- 用途：電影和電視節目資訊、海報和串流平台可用性
- 分享的資料：包含您所選地區的 API 請求
- 隱私權政策：[https://www.themoviedb.org/privacy-policy](https://www.themoviedb.org/privacy-policy)

**OMDb API**
- 用途：IMDb 和 Rotten Tomatoes 評分
- 分享的資料：用於查詢評分的電影/電視節目識別碼
- 隱私權政策：[https://www.omdbapi.com/legal.htm](https://www.omdbapi.com/legal.htm)

### 使用者控制權

您對您的資料擁有完全控制權：
- **刪除 API 金鑰**：隨時可在設定中移除您的 API 金鑰
- **清除快取**：刪除應用程式即可移除所有快取資料
- **無需帳號**：本應用程式無需建立任何帳號即可使用

### 兒童隱私

本應用程式不會故意收集 13 歲以下兒童的資訊。本應用程式顯示的電影評級和內容資訊可能包含成人主題。

### 政策變更

我們可能會不時更新本隱私權政策。任何變更都會反映在上方的「最後更新」日期中。

### 聯絡方式

## 日本語

### 概要

WatchNext（以下「本アプリ」）は、各ストリーミングプラットフォームでコンテンツを検索するための映画・テレビ番組検索アプリケーションです。このプライバシーポリシーでは、お客様の情報の取り扱いについて説明します。

### データ収集

**収集するデータ：**
- **APIキー**：ご自身のTMDBまたはOMDb APIキーを入力された場合、それらはお客様のデバイスにのみローカル保存されます。
- **ユーザー設定**：選択した地域、ストリーミングプラットフォーム、フィルター設定はローカルに保存されます。
- **キャッシュデータ**：映画やテレビ番組の情報は、パフォーマンス向上のためデバイスに一時的にキャッシュされます。

**収集しないデータ：**
- 個人識別情報
- 位置情報
- 利用分析データ
- ローカルキャッシュ以外の閲覧履歴

### データ保存

すべてのデータは、AppleのSwiftDataフレームワークを使用してデバイスにローカル保存されます。当方はサーバーを運営していないため、データが当方のサーバーに送信されることはありません。

### サードパーティサービス

本アプリは以下のサードパーティAPIを使用しています：

**TMDB（The Movie Database）**
- 目的：映画・テレビ番組情報、ポスター、ストリーミング配信状況
- 共有されるデータ：選択した地域を含むAPIリクエスト
- プライバシーポリシー：[https://www.themoviedb.org/privacy-policy](https://www.themoviedb.org/privacy-policy)

**OMDb API**
- 目的：IMDbおよびRotten Tomatoes評価
- 共有されるデータ：評価検索用の映画/テレビ番組識別子
- プライバシーポリシー：[https://www.omdbapi.com/legal.htm](https://www.omdbapi.com/legal.htm)

### ユーザーコントロール

お客様はご自身のデータを完全にコントロールできます：
- **APIキーの削除**：設定からいつでもAPIキーを削除可能
- **キャッシュのクリア**：アプリを削除するとすべてのキャッシュデータが削除されます
- **アカウント不要**：本アプリはアカウント作成なしで利用可能

### 子供のプライバシー

本アプリは13歳未満の子供から意図的に情報を収集することはありません。本アプリは、成人向けテーマを含む可能性のある映画評価やコンテンツ情報を表示します。

### ポリシーの変更

このプライバシーポリシーは随時更新される場合があります。変更は上記の「最終更新」日に反映されます。
