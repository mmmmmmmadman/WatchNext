WatchNext

A cross-platform streaming content search tool for movies and TV shows.

macOS 14.0+ iOS 17.0+

Features

  • Search content across Apple TV, Netflix, Prime Video, Disney+
  • Ratings from TMDB, IMDb, Rotten Tomatoes
  • Multi-region support
  • iCloud favorites sync

FAQ

How to set up API Key?

Enter your TMDB API Key in the app's Settings.

Is it free?

The app is free, but you need to obtain a free TMDB API Key.

Which regions are supported?

Taiwan, USA, Japan, South Korea, Hong Kong, UK, Canada, Australia, Germany, France.

Contact & Support

Submit bug reports or feature requests via GitHub Issues.

Privacy

WatchNext does not collect any personal data. iCloud sync uses Apple's CloudKit service.
