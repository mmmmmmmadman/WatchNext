WatchNext 幫助您在一個地方探索多個串流平台上的電影和電視節目。

不再需要在不同 App 之間切換來尋找想看的內容。WatchNext 讓您瀏覽 Apple TV、Netflix、Prime Video 和 Disney+ 上的內容，並提供強大的篩選功能。

功能特色

- 依平台瀏覽：查看您喜愛的串流服務上有哪些內容
- 多重評分：顯示 TMDB 評分，選擇性加入 IMDb 和 Rotten Tomatoes 評分
- 智慧篩選：依類型篩選，依標題、上映日期或評分排序
- 區域支援：尋找您所在國家可觀看的內容
- 簡潔介面：專注於探索的極簡設計

使用方式

1. 選擇您的串流平台
2. 選擇您的地區
3. 瀏覽電影或電視節目
4. 依類型篩選並依評分排序
5. 點擊任何標題查看詳情

WatchNext 使用 TMDB API 取得電影和電視資料。選擇性整合 OMDb 可加入 IMDb 和 Rotten Tomatoes 評分。

注意：需要 API 金鑰才能使用完整功能。可從 TMDB 和 OMDb 免費取得金鑰。

各平台的支援範圍因地區而異，並非所有串流平台都對應全部國家。
